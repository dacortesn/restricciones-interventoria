# Matriz de restricciones – Interventoría Ciclorrutas Sabana

Mapa interactivo para el seguimiento de la interventoría a la matriz de restricciones por tramo de las ciclorrutas de la Sabana (ICCU).

- Datos: hoja «MATRIZ RESTRICCIONES», leída en vivo cada vez que se abre la página (con un corte guardado de respaldo).
- Ejes y abscisas: KML del proyecto.
- Predios: capa de terrenos del IGAC (SINIC_DA), a 15 m o menos del eje.
- Incluye el botón «Mi ubicación», que se calcula en el dispositivo y no se envía a ningún servidor.

Todo el sitio es un solo archivo, index.html.
